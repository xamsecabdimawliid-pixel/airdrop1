# SAIB
## Somali Airdrop Intelligence Bot 🇸🇴

A Telegram bot for discovering and screening
crypto airdrop opportunities.

### Features

- Somali Telegram notifications
- A+ / A / B+ grading
- Security screening
- Free airdrop filtering
- MetaMask and Trust Wallet guidance
- Duplicate detection
- Admin commands
- SQLite database

### Requirements

- Python 3.11+
- Telegram Bot Token
- Telegram Admin User ID

### Installation

1. Clone the repository.

2. Install dependencies:

   pip install -r requirements.txt

3. Copy .env.example to .env.

4. Add your Telegram bot token.

5. Add your Telegram user ID.

6. Start the bot:

   python main.py

### Telegram Commands

/start
/help
/stats
/scan

### Security

Never store wallet seed phrases or private keys.
Never trust an airdrop solely because it has
a high security score.
